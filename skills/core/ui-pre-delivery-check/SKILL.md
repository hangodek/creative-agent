# UI Pre-Delivery Quality Checklist

Before declaring any UI task, component, or view complete, you MUST mentally or programmatically verify your code against this 7-point quality gate. This checklist prevents the most common subtle bugs in AI-generated user interfaces.

---

## The 7 Mandatory Pre-Delivery Checks

| # | Inspection Item | Verification Rule | Fix if Missing |
|---|-----------------|-------------------|----------------|
| 1 | **No Emoji Icons** | All icons must use SVG primitives (Lucide / Heroicons / Phosphor). Never use Unicode emojis as UI control icons. | Replace `<span>🗑️</span>` with `<Trash2 className="w-4 h-4" />`. |
| 2 | **Clickable Cursor** | All interactive buttons, cards, tabs, and toggles must have `cursor-pointer`. | Add `cursor-pointer` to clickable button/div classes. |
| 3 | **WCAG AA Contrast** | Body text must achieve at least **4.5:1** contrast ratio against its direct background in both light and dark modes. | Darken muted text on light mode; brighten muted text on dark mode. |
| 4 | **Focus-Visible Rings** | Every button, link, and input must have an accessible focus indicator for keyboard users (`Tab` key navigation). | Add `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2`. |
| 5 | **Motion Accessibility** | Animations and spring transitions must respect `prefers-reduced-motion`. | Wrap transitions in `motion-reduce:transition-none` or `motion-safe:animate-...`. |
| 6 | **Responsive Fluidity** | UI must render without horizontal overflow, clipped badges, or awkward wrapping at **375px** (mobile), **768px** (tablet), and **1280px** (desktop). | Use `flex-wrap`, responsive grids (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`), and `truncate`/min-width clamps. |
| 7 | **Tabular Numbers** | All columns containing numbers, prices, timestamps, or stats must use tabular figures to prevent horizontal jittering. | Add `tabular-nums` or `font-mono tabular-nums`. |

---

## Verification Protocol

Before saying *"I have finished building the component"*:
1. Review the diff against all 7 checklist points above.
2. If any check fails, fix it immediately in the code before handing off to the user.
